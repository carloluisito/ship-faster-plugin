# Layout

## Map
| Directory | Responsibility |
|---|---|
| `.claude-plugin/` | marketplace manifest; lists the plugin with source `./plugins/ship-faster` |
| `.github/workflows/` | CI workflow `ci.yml` and eval workflow `evals.yml` |
| `docs/superpowers/specs/` | design spec for the whole plugin |
| `docs/superpowers/plans/` | implementation plans (foundation, knowledge, shipping) |
| `plugins/ship-faster/.claude-plugin/` | plugin manifest `plugin.json` (name, version) |
| `plugins/ship-faster/skills/` | one directory per skill holding `SKILL.md`; onboard, ship, release, and health also have `reference/` |
| `plugins/ship-faster/agents/` | one `.md` per subagent |
| `plugins/ship-faster/hooks/` | `hooks.json` registering the hook scripts |
| `plugins/ship-faster/scripts/` | CLI scripts and `hook-*.mjs` hook entry points |
| `plugins/ship-faster/scripts/lib/` | shared modules imported by scripts and tests |
| `plugins/ship-faster/templates/` | skeletons for generated files; `pages/` holds the wiki page templates |
| `plugins/ship-faster/evals/` | one eval case per skill |
| `plugins/ship-faster/tests/` | `node:test` suites, helpers, runner, validator, benchmark, eval runners (`evals.sh`, `evals.ps1`, `eval-report.mjs`) |

`plugins/ship-faster/evals/results/` and `.claude/worktrees/` are gitignored. `docs/wiki/index.md` is generated by `plugins/ship-faster/scripts/index.mjs`; do not edit it by hand.

## Entry points
| Entry | Starts | File |
|---|---|---|
| SessionStart (startup, resume, clear, compact, fork), 10 s | wiki and plan report | `plugins/ship-faster/scripts/hook-session-start.mjs` |
| PreToolUse on Bash, 5 s | git guard | `plugins/ship-faster/scripts/hook-ship-guard.mjs` |
| PostToolUse on Edit, Write, MultiEdit, NotebookEdit, 5 s | covered-page recording | `plugins/ship-faster/scripts/hook-drift-marker.mjs` |
| UserPromptSubmit, 5 s | touched-page report | `plugins/ship-faster/scripts/hook-prompt-report.mjs` |
| SessionEnd, 5 s | session record cleanup | `plugins/ship-faster/scripts/hook-session-end.mjs` |
| `/ship-faster:onboard`, `/ship-faster:sync-docs`, `/ship-faster:lesson` | knowledge skills | `plugins/ship-faster/skills/onboard/SKILL.md` and siblings |
| `/ship-faster:kickoff`, `/ship-faster:preflight`, `/ship-faster:review`, `/ship-faster:ship`, `/ship-faster:release`, `/ship-faster:health` | shipping skills | `plugins/ship-faster/skills/ship/SKILL.md` and siblings |
| Test runner | every `*.test.mjs` with `CLAUDE_PLUGIN_DATA` set to a temp directory | `plugins/ship-faster/tests/run.mjs` |
| Validator | manifest, hook, skill, agent, eval, and template checks | `plugins/ship-faster/tests/validate.mjs` |

## Where things go
| Adding a… | Put it in | Named like | Register in |
|---|---|---|---|
| CLI script | `plugins/ship-faster/scripts/` | `<name>.mjs` | Scripts block of `plugins/ship-faster/README.md` |
| hook | `plugins/ship-faster/scripts/` | `hook-<name>.mjs` | `plugins/ship-faster/hooks/hooks.json` |
| shared module | `plugins/ship-faster/scripts/lib/` | `<topic>.mjs` | nothing |
| test | `plugins/ship-faster/tests/` | `<module>.test.mjs` | nothing; the runner picks up every `*.test.mjs` |
| skill | `plugins/ship-faster/skills/<name>/` | `SKILL.md` with frontmatter `name` equal to the directory | an eval case in `plugins/ship-faster/evals/<name>/` (the validator requires one) |
| agent | `plugins/ship-faster/agents/` | `<name>.md` with frontmatter `name` equal to the file name | nothing |
| template | `plugins/ship-faster/templates/` or its `pages/` | `<kind>.md` | `TEMPLATES` in `plugins/ship-faster/tests/validate.mjs`, and in `plugins/ship-faster/tests/templates.test.mjs` the file list of the "every template file exists" test (top level) or `PAGES` (`pages/`) |
| eval case | `plugins/ship-faster/evals/<skill>/` | `prompt.md`, `case.yaml`, `scaffold.sh`, `graders/*.md` | nothing |
